# План реализации нереализованных функций ToroidalDB

## Приоритеты реализации

| Приоритет | Описание |
|-----------|----------|
| P0 | Критические функции для базовой работоспособности |
| P1 | Высокий приоритет для стабильности и производительности |
| P2 | Средний приоритет для расширенной функциональности |
| P3 | Низкий приоритет для дополнительных возможностей |

---

## Этап 1: Фундаментальные улучшения (Foundation)

### 1.1 Пулы объектов (Object Pools)

**Приоритет:** P1  
**Зависимости:** Нет  
**Описание:** Оптимизация выделения памяти для частых операций с Node и Edge

#### Задачи

- [ ] Создать `src/core/memory/pool.rs`
  - Реализовать `ObjectPool<T>` trait
  - Добавить `PoolConfig` для настройки размера пула
  - Реализовать `acquire()` и `release()` методы

- [ ] Создать `src/core/memory/node_pool.rs`
  - Реализовать пул для `Node` объектов
  - Добавить предварительное выделение (pre-allocation)
  - Реализовать сброс состояния при возврате в пул

- [ ] Создать `src/core/memory/edge_pool.rs`
  - Реализовать пул для `Edge` объектов
  - Оптимизировать для частых созданий/удалений

- [ ] Интегрировать пулы в хранилище
  - Обновить `src/storage.rs` для использования пулов
  - Добавить метрики использования пулов

## Этап 2: Расширение TQL (Core Features)

### 2.1 Векторные операции

**Приоритет:** P0  
**Зависимости:** Нет  
**Описание:** Добавить функции сравнения и операции над векторами

#### Задачи

- [ ] Создать `src/tql/functions/vector/comparison.rs`
  - Реализовать `cosine_similarity(v1: &[f32], v2: &[f32]) -> f32`
  - Реализовать `euclidean_distance(v1: &[f32], v2: &[f32]) -> f32`
  - Реализовать `manhattan_distance(v1: &[f32], v2: &[f32]) -> f32`
  - Добавить оптимизации SIMD

- [ ] Создать `src/tql/functions/vector/operations.rs`
  - Реализовать `vector_add(v1: &[f32], v2: &[f32]) -> Vec<f32>`
  - Реализовать `vector_subtract(v1: &[f32], v2: &[f32]) -> Vec<f32>`
  - Реализовать `vector_normalize(v: &[f32]) -> Vec<f32>`
  - Реализовать `vector_magnitude(v: &[f32]) -> f32`
  - Реализовать `vector_dot_product(v1: &[f32], v2: &[f32]) -> f32`

- [ ] Создать `src/tql/functions/vector/mod.rs`
  - Объединить модули comparison и operations
  - Зарегистрировать функции в TQL

- [ ] Обновить парсер TQL
  - Добавить поддержку новых функций в грамматику

### 2.2 Расширение синтаксиса TQL

**Приоритет:** P2  
**Зависимости:** 2.1  
**Описание:** Добавить поддержку CTE, оконных функций, рекурсивных запросов

#### Задачи

- [ ] Реализовать CTE (Common Table Expressions)
  - Обновить `src/tql/parser.rs`
    - Добавить правило для `WITH` запросов
    - Поддержка `WITH RECURSIVE`
  - Обновить `src/tql/executor.rs`
    - Реализовать создание временных представлений
    - Обработка рекурсивных CTE

- [ ] Реализовать оконные функции
  - Обновить `src/tql/ast.rs`
    - Добавить `WindowFunction` variant
    - Добавить `OVER` clause
  - Создать `src/tql/functions/window.rs`
    - Реализовать `ROW_NUMBER()`
    - Реализовать `RANK()` и `DENSE_RANK()`
    - Реализовать `LAG()` и `LEAD()`
    - Реализовать `FIRST_VALUE()` и `LAST_VALUE()`
  - Обновить исполнитель для оконных функций

- [ ] Реализовать рекурсивные запросы
  - Создать `src/tql/executor/recursive.rs`
  - Реализовать движок рекурсивных запросов
  - Оптимизировать для больших глубин
