# Графовые обходы в TQL v2.0

## Обзор

TQL v2.0 поддерживает графовые обходы, позволяя находить связи между узлами в графе данных ToroidalDB. Это позволяет выполнять сложные запросы, которые учитывают не только векторное сходство, но и структурные связи между данными.

## Синтаксис графовых паттернов

### Направленные связи

Для представления направленных связей используется стрелочный синтаксис:

```
MATCH (source:Label)-[:RELATIONSHIP_TYPE]->(target:Label)
```

Примеры:
- `(user:User)-[:FOLLOWS]->(other:User)`
- `(customer:Customer)-[:PURCHASED]->(product:Product)`
- `(author:Author)-[:WROTE]->(book:Book)`

### Обратные связи

Для поиска обратных связей используется стрелка в противоположном направлении:

```
MATCH (source:Label)<-[:RELATIONSHIP_TYPE]-(target:Label)
```

Примеры:
- `(post:Post)<-[:WROTE]-(author:Author)`
- `(comment:Comment)<-[:MADE]-(user:User)`

### Ненаправленные связи

Для поиска любых связей между узлами (независимо от направления):

```
MATCH (node1:Label)-[:RELATIONSHIP_TYPE]-(node2:Label)
```

Примеры:
- `(person1:Person)-[:FRIENDS_WITH]-(person2:Person)`
- `(company1:Company)-[:PARTNER_OF]-(company2:Company)`

## Структуры для представления отношений

В AST (абстрактном синтаксическом дереве) определены следующие структуры:

### `RelationshipPattern`
```rust
pub struct RelationshipPattern {
    pub type_: String,        // Тип связи (например, "FOLLOWS", "FRIENDS_WITH")
    pub direction: Direction, // Направление связи
}
```

### `Direction`
```rust
pub enum Direction { 
    Outgoing,  // ->
    Incoming,  // <-
    Both,      // -
}
```

### `MatchClause`
```rust
pub struct MatchClause {
    pub source: NodePattern,              // Исходный узел
    pub relationship: Option<RelationshipPattern>, // Связь (опционально)
    pub target: Option<NodePattern>,      // Целевой узел (опционально)
}
```

## Примеры запросов с графовыми обходами

### Простой графовый обход
```
MATCH (user:User)-[:FOLLOWS]->(followed:User) 
RETURN user.id, followed.id
```

### Поиск друзей друзей
```
MATCH (user:User)-[:FOLLOWS]->(friend:User)-[:FOLLOWS]->(friend_of_friend:User) 
RETURN user.id, friend_of_friend.id
```

### Поиск взаимных связей
```
MATCH (user1:User)-[:FOLLOWS]-(user2:User) 
RETURN user1.id, user2.id
```

### Смешанный запрос (граф + векторный поиск)
```
MATCH (user:User)-[:FOLLOWS]->(similar:User) 
WHERE TOROIDALDISTANCE(similar.vector, 0.3) 
RETURN user.id, similar.id, similar.score
```

## Поддержка направленных и ненаправленных рёбер

### Направленные рёбра
- Используют синтаксис `->` или `<-`
- Представляют асимметричные отношения (например, "подписка", "следование", "авторство")
- Возвращают связи только в указанном направлении

### Ненаправленные рёбра
- Используют синтаксис `-`
- Представляют симметричные отношения (например, "дружба", "партнерство", "совместная работа")
- Возвращают связи в обоих направлениях

## Реализация в парсере

Парсер в `src/tql/parser.rs` поддерживает разбор всех типов графовых паттернов:

- `parse_relationship_pattern()` - разбирает синтаксис связей
- Поддержка всех трех направлений (->, <-, -)
- Извлечение типа связи
- Интеграция с остальными частями запроса

## Реализация в исполнителе

Исполнитель в `src/tql/executor.rs` и модуле `src/tql/graph.rs` реализует:

- Поиск соседей узла с помощью `store.get_neighbors()`
- Bidirectional BFS алгоритм для поиска в пределах заданного количества шагов
- Учет типа связи при обходе графа
- Интеграция с векторным поиском для гибридных запросов

## Тестирование

Графовые обходы тщательно протестированы в модуле `src/tql/graph_traversal_tests.rs`:

- Тесты разбора синтаксиса связей
- Тесты направленных и ненаправленных рёбер
- Тесты выполнения запросов на тестовых данных
- Тесты сложных графовых паттернов

## Ограничения и будущие улучшения

### Текущие ограничения
- Поддержка только простых паттернов (A)-[R]->(B)
- Ограниченная поддержка сложных графовых паттернов (например, цепочек из нескольких рёбер)
- Векторный поиск не полностью интегрирован с графовыми обходами

### Будущие улучшения
- Поддержка сложных графовых паттернов (A)-[R1]->(B)-[R2]->(C)
- Улучшенная интеграция векторного и графового поиска
- Поддержка свойств рёбер
- Алгоритмы для поиска путей и циклов

## Заключение

TQL v2.0 предоставляет мощные возможности для выполнения графовых обходов, позволяя пользователям исследовать структурные связи в данных ToroidalDB. Синтаксис интуитивно понятен и совместим с современными графовыми языками запросов, при этом сохраняя возможность интеграции с тороидальным векторным поиском.
